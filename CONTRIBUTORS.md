# Contributors

Senior Angular Interview Prep welcomes contributions from developers, reviewers, and technical writers. Questions, corrections, documentation, and review feedback all help improve the project.

## Recognition

The [GitHub contributor history](https://github.com/QuinntyneBrown/senior-angular-interview-prep/graphs/contributors) records authors of merged commits. Pull requests and issues also preserve credit for reviews, proposals, and other contributions that may not appear in commit history.

When collaborating on a contribution, credit co-authors in the commit and acknowledge reviewers or other participants in the pull request description. Use each person's preferred public name or GitHub handle, and obtain permission before adding personal information.

## Become a contributor

Read [CONTRIBUTING.md](CONTRIBUTING.md) to get started. No prior contribution to the project is required.
