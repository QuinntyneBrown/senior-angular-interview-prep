# Security Policy

## Scope

This repository currently contains documentation and does not distribute an application or package. Security concerns may still include exposed credentials, malicious links, or examples that encourage unsafe handling of data.

## Reporting a concern

Do not disclose credentials, exploit details, or private information in public issues or pull requests.

If GitHub private vulnerability reporting is enabled, use **Report a vulnerability** in the repository's **Security** tab. Otherwise, use a private contact method listed on the repository owner's GitHub profile. If none is available, open an issue requesting a private security contact without disclosing the concern's sensitive details.

Include the affected file or example, a description of the concern, its potential impact, and a suggested correction if available. Redact secrets and personal information.

## Review and corrections

Security corrections are handled through repository updates. This project has no versioned release support policy or guaranteed response time at this stage.

Ordinary technical inaccuracies that do not expose sensitive information can be reported through [GitHub issues](https://github.com/QuinntyneBrown/senior-angular-interview-prep/issues).
