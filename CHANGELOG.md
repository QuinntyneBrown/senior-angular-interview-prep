# Changelog

Notable changes to the learning material and project documentation are recorded here.

## Unreleased

### Added

- 23 questions with answers for engineers who build a shared Angular component library, about 4 hours 40 minutes of interview time across signals, design tokens, accessibility, component API design, versioning, testing, and zoneless change detection, including a 40-minute live-coding exercise.
- A standard question format with scenario, hints, answer, scoring table, follow-up questions, and references, and a template for new questions.
- `npm run check` and `npm run index`: validate every question's front matter and sections, and generate the question index.
- `npm run verify:examples`: compile TypeScript examples with the Angular compiler and strict template type checking.
- A continuous integration workflow that runs both checks on pull requests.
- Root README describing the project's purpose, planned scope, and current status.
- Contribution guidelines and a standard interview question format.
- Contributor recognition, community conduct, and security reporting documentation.
- Issue and pull request templates for content contributions.
- MIT license.
